# 📊 Data Analytics Project | Power BI Dashboard

## 1. Project Overview

This project focuses on analyzing structured data using Microsoft Power BI to generate meaningful business insights through interactive visualizations.

The project involves importing a CSV dataset into Power BI, cleaning and transforming data using Power Query, creating calculated measures using DAX, and developing an interactive dashboard to analyze key performance indicators (KPIs), trends, and business performance.

**Project Objectives:**
- Import and explore CSV data in Power BI.
- Clean and transform data using Power Query.
- Handle missing values, duplicates, and inconsistent data.
- Create calculated measures using DAX.
- Develop interactive visualizations.
- Identify trends, patterns, and key business insights.
- Present analytical findings through an interactive dashboard.

## 3. Project Workflow

### Step 1: Data Loading
- Imported the CSV dataset into Power BI Desktop.
- Explored the dataset structure and column names.
- Checked data types and identified important attributes.
- Reviewed the dataset for data quality issues.

### Step 2: Data Cleaning & Transformation (Power Query)
- Identified and handled missing or null values.
- Removed duplicate records where appropriate.
- Corrected column data types.
- Renamed columns for better readability.
- Standardized inconsistent data formats.
- Removed unnecessary columns.
- Prepared the cleaned dataset for analysis.

### Step 3: Data Modeling
- Created relationships between tables, where required.
- Organized fields for efficient reporting.
- Validated the data model.
- Ensured accurate filtering and aggregation.

### Step 4: DAX Measures & KPI Creation
Created calculated measures using DAX to track important business metrics.

Examples:
- Total Sales
- Average Sales
- Number of Items
- Average Rating


### Step 5: Dashboard Development
Designed an interactive Power BI dashboard using different visualizations:

- **KPI Cards:** Display important business metrics and performance indicators.
- **Bar Charts:** Compare sales or performance across different categories.
- **Line Charts:** Analyze trends and performance over time.
- **Donut Charts:** Show category-wise or segment-wise distribution.
- **Slicers:** Enable dynamic filtering based on selected attributes.

## 6. How to Run the Project

Follow these steps to explore the Power BI dashboard:

**Step 1: Clone the Repository**

```bash
git clone https://github.com/your-username/your-repository-name.git
```

**Step 2: Navigate to the Project Folder**

```bash
cd your-repository-name
```

**Step 3: Open Power BI Desktop**
- Install Microsoft Power BI Desktop.
- Open the downloaded `.pbix` file.

**Step 4: Connect the Dataset**
- Ensure the CSV dataset is available in the Dataset folder.
- Update the file path in the data source settings if required.
- Open Power Query Editor to review the transformations.

**Step 5: Refresh the Dashboard**
- Click Refresh in Power BI Desktop.
- Verify that the data has loaded correctly.
- Explore the dashboard using charts, KPI cards, and slicers.
